Teams of robots searching a disaster area, simulated step by step

SWARM is an open-source research simulator. Drones and ground robots look for survivors on a grid with hazards, flat batteries, a lossy radio link and robots that fail. Every run is deterministic: the same seed and configuration always give the same episode.

Below are real episodes recorded with SWARM, replayed in your browser. To run new ones, install it and use the local dashboard.

How it works

One deterministic 2D environment is the only simulator. Robots get observations and messages, never ground truth. Everything else reads the environment's event stream: metrics, experiments, the dashboard, the 3D view and this site.

Design decisions are recorded as ADRs in docs/decisions; the complete status is in docs/25.

Limitations

  • SWARM is a simulator for research. It does not control real aircraft or robots and is not validated for real disaster operations.
  • The world is a 2D grid; every robot moves one cell per step. Hazards, sensing and the radio channel are simple probabilistic models.
  • The 3D view is a kinematic replay of the 2D episode in MuJoCo. It checks collisions and line of sight; it is not a flight simulation.
  • The MARL policies were trained with a small CPU budget on one scenario.
  • At the default time limits almost every coordinated run succeeds, so most findings are about search speed.

Run it yourself

Python 3.12 to 3.14; the core needs only NumPy. The demo runs two scenarios in a few seconds, then the dashboard runs new episodes, comparisons and exports on your machine.

git clone https://github.com/Exit0Hero/SWARM.git
cd SWARM
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\Activate.ps1
python -m pip install -e .
swarm demo
swarm dashboard --data-dir swarm-demo/dashboard      # http://127.0.0.1:8765/
