# SWARM Development Roadmap

## Phase 0 — Inspect and stabilize
Acceptance: repository audit, architecture decision record, environment setup, test command, baseline CI.

## Phase 1 — Deterministic 2D core
Acceptance: seeded scenarios, state transitions, action validation, obstacles, agents, resource rules, unit/integration tests.

## Phase 2 — Baselines and metrics
Acceptance: random and heuristic policies, documented metrics, multi-seed evaluation, exported results.

## Phase 3 — Coordination under constraints
Acceptance: task allocation, local observations, communication range/dropout/latency, reassignment, failure scenarios.

## Phase 4 — MARL
Acceptance: compatible multi-agent API, training/evaluation separation, first learned baseline, checkpointing, reproducible evaluation.

## Phase 5 — Perception
Acceptance: synthetic sensor benchmarks and replaceable perception interface; vision model only with justified data and evaluation plan.

## Phase 6 — Visualization and research reporting
Acceptance: live/replay visualization, experiment comparison, documented limitations and reproducible report.

## Phase 7 — 3D feasibility study
Acceptance: evidence-based simulator choice, integration prototype, performance/cost assessment, decision to proceed or defer.
